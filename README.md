## 🌟 Portfolio Key Features

- 🎨 **Glassmorphism Design System**: Glassmorphic cards with responsive dark & light theme modes.
- 🌌 **Particle Background Layer**: Smooth canvas particle animation layer.
- ⌨️ **Dynamic Typewriter Subtitle**: Animated title switching between Full-Stack Developer, Cloud Security Enthusiast, and Problem Solver.
- 📸 **3D Tilt Profile Card**: Dynamic mouse-tilt photo card featuring custom portrait frame and floating achievement badges.
- 🛠️ **Live GitHub Showcase**: Integrated grid featuring 9 repositories with live Vercel links (AI Gadget Advisor, Cloud Bus Pass, CodeCheck AI, Assistant AI, VeriTrust Ledger Guardian, etc.).
- 📄 **Curriculum Vitae Section**: View online & download options for 2 official PDF resume formats.
- 🎓 **VTU Markcards & Certifications Hub**: Interactive tab filtering displaying Semester 1 to Semester 6 VTU Markcards and 7 industry certifications (AWS, IBM, Microsoft, MathWorks, Infosys, Saylor.org, Wadhwani).
- 📱 **Fully Responsive Layout**: Built with mobile-first CSS flexbox and CSS grid layout system.

## ⚡ How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Darshankbd/web-portfolio.git
   cd web-portfolio
   ```

2. **Open in browser**:
   - Double-click `index.html` or open via VS Code Live Server / Python HTTP server:
   ```bash
   python -m http.server 8000
   ```
   - Open `http://localhost:8000` in your web browser.
